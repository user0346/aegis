# Zusatz-Wissen: IT-Sicherheit & Technik (kuratiert)

Kurze, sachliche Definitionen zu wichtigen IT-Sicherheits- und Technik-Begriffen — damit AEGIS von Anfang an ein solides Fundament hat.

Windows-Registrierungsdatenbank: Die Windows-Registrierungsdatenbank ist die zentrale Konfigurationsdatenbank von Windows. Sie speichert Einstellungen für das Betriebssystem und Anwendungen. Sie ist seit Windows NT existent und hierarchisch aufgebaut.

PowerShell: PowerShell ist ein plattformübergreifendes Tool von Microsoft zur Systemautomatisierung und -verwaltung. Es kombiniert einen Kommandozeileninterpreter mit einer Skriptsprache und ermöglicht die Steuerung von Windows und anderen Systemen.

Virtual Private Network: Ein Virtual Private Network schafft eine verschlüsselte Verbindung, die den Datenverkehr vor unbefugtem Zugriff schützt. Es ermöglicht den Zugriff auf Netzwerke wie ein Firmennetzwerk aus externen Standorten. Es gibt zwei Haupttypen: das konventionelle VPN und das virtuelle Privatnetzwerk im Sinne einer verschlüsselten Internetverbindung.

Transport Layer Security: Transport Layer Security verschlüsselt Daten im Internet, um sie vor unbefugtem Zugriff zu schützen. Es ersetzt das ältere SSL-Protokoll und wird bei HTTPS-Verschlüsselungen verwendet. TLS sichert beispielsweise Browser-Verbindungen und Server-Kommunikation.

Public-Key-Infrastruktur: Die Public-Key-Infrastruktur ist ein System zur Verwaltung von digitalen Zertifikaten. Sie sichert Kommunikation durch die Verifikation von Identitäten und Schlüsseln. Zertifikate werden von vertrauenswürdigen Stellen ausgestellt und überprüft.

Kryptologische Hashfunktion: Sie nimmt Daten beliebiger Länge auf und verarbeitet sie zu einer festlängigen, unveränderlichen Kette von Zeichen, die als Hashwert bezeichnet wird. Dieser Hashwert ist sehr sensibel gegenüber Änderungen der Eingabedaten und fast eindeutig.

Sandbox: Sandbox bedeutet eine isolierte Umgebung, in der Aktionen getestet werden können ohne dass diese außerhalb des Sandboxes-Bereichs irgendeine Auswirkung haben.

Patch (Software): Ein Patch ist eine Korrekturauslieferung zur Behebung von Fehlern und Sicherheitslücken in Software. Er kann auch neue Funktionen einbeziehen, ohne dass die Nutzer es immer wissen. Größere Updates enthalten oft mehrere Patches zusammen.

Advanced Persistent Threat: Ein Advanced Persistent Threat ist ein dauerhafter, spezialisierter Angriff auf IT-Systeme, bei dem die Angreifer langfristig und zielgenau vorgehen, um vertrauliche Daten zu stehlen oder Schäden anzurichten.

Spear-Phishing: Spear-Phishing ist ein spezialisierter Form von Phishing, bei dem der Angriff auf eine bestimmte Person oder Organisation zugeschnitten wird. Hierbei werden personalisierte Nachrichten und Links verwendet, um den Zielpersonal zu täuschen und sie dazu zu bringen, vertrauliche Informationen preiszugeben oder gefährliche Aktionen durchzuführen.

Drive-by-Download: Ein Drive-by-Download passiert, wenn du unbewusst Schadsoftware herunterlädst, indem du nur eine Website besuchst. Das Nutzen von Sicherheitslücken im Browser oder Betriebssystem macht das Risiko noch größer.

Rechteausweitung: Rechteausweitung bedeutet, dass ein Benutzer oder eine Anwendung zusätzliche Berechtigungen erlangt, um auf Ressourcen zuzugreifen, die ihnen normalerweise nicht zugestanden sind. Dies kann durch Ausnutzung von Softwarefehlern oder Schwachstellen erreicht werden.

DNS-Spoofing: DNS-Spoofing manipuliert die Domain-Name-Server-Zuordnung, um den Benutzer auf eine falsche Website zu locken. Das Ziel ist oft Phishing und das Eindringen in Privatsphäre durch Schadsoftware.

ARP-Spoofing: ARP-Spoofing ist das absichtliche Senden falscher ARP-Nachrichten. Dadurch werden die ARP-Tabellen in einem Netzwerk manipuliert, was zur Abwehr oder Veränderung von Datenverkehr genutzt werden kann. Dies ermöglicht Man-in-the-Middle-Angriffe in lokalen Netzwerken.

Datenexfiltration: Datenexfiltration ist der unbefugte Diebstahl von sensiblen Daten. Dabei werden vertrauliche Informationen aus einem System oder Netzwerk entwendet. Dies stellt eine erhebliche Bedrohung für die Datensicherheit dar.

Sicherungskopie: Eine Datensicherung ist die Erstellung einer Kopie von Daten auf einem anderen Speichermedium. Dies dient der Wiederherstellung von Daten im Falle eines Datenverlustes. Es ist ein wesentlicher Bestandteil der Datensicherheit.

Schadprogramm: Schadprogramme sind Computerprogramme, die unerwünschte oder schädliche Funktionen ausführen. Sie werden oft als Malware bezeichnet, was einen breiteren Schutz vor potenziell gefährlicher Software umfasst. Der Begriff Virus beschreibt dabei meist nur einen Teilaspekt des Schutzes vor Schadsoftware.

Spam: Spam ist unerwünschte, massenhaft übermittelte Nachrichten, die ohne Zustimmung des Empfängers zugestellt werden. Spamming, oder Spammen, wird von Personen, den sogenannten Spammern, durchgeführt. Oftmals enthält Spam Werbung oder andere unerwünschte Informationen.

Captcha: Captcha steht für „Completely Automated Public Turing test to tell Computers and Humans Apart“. Es ist eine Methode zur Unterscheidung zwischen menschlichen und automatisierten Benutzern. Captchas werden hauptsächlich eingesetzt, um automatisierte Eingaben in Online-Formulare zu verhindern.

Digitale Signatur: Die digitale Signatur basiert auf einem asymmetrischen Kryptosystem. Ein Sender nutzt einen geheimen Schlüssel, um eine digitale Signatur für eine Nachricht zu erstellen. Diese Signatur kann mit dem entsprechenden öffentlichen Schlüssel überprüft werden, um die Authentizität und Unveränderung der Nachricht zu bestätigen.

Honeypot: Honigtöpfe sind Einrichtungen, die Angreifer durch scheinbare Ziele anlocken sollen. Das Ziel ist es, die Aufmerksamkeit des Angreifers von den eigentlichen Systemen abzulenken. Der Begriff leitet sich von der Beobachtung ab, dass Bären durch Honigköpfe sowohl abgelenkt als auch in eine Falle gelockt werden.
