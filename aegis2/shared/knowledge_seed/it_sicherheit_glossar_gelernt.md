Advanced Persistent Threat: Ein Advanced Persistent Threat ist ein dauerhafter, spezialisierter Angriff auf IT-Systeme, bei dem die Angreifer langfristig und zielgenau vorgehen, um vertrauliche Daten zu stehlen oder Schäden anzurichten.

ARP-Spoofing: ARP-Spoofing ist das absichtliche Senden falscher ARP-Nachrichten. Dadurch werden die ARP-Tabellen in einem Netzwerk manipuliert, was zur Abwehr oder Veränderung von Datenverkehr genutzt werden kann. Dies ermöglicht Man-in-the-Middle-Angriffe in lokalen Netzwerken.

Bug-Bounty-Programm: Ein Bug-Bounty-Programm belohnt Sicherheitsforscher für die Aufdeckung von Schwachstellen. Die teilnehmenden Organisationen zahlen Prämien für erfolgreiche Meldungen. Das Ziel ist die Verbesserung der Sicherheit durch externe Expertise.

Captcha: Captcha steht für „Completely Automated Public Turing test to tell Computers and Humans Apart“. Es ist eine Methode zur Unterscheidung zwischen menschlichen und automatisierten Benutzern. Captchas werden hauptsächlich eingesetzt, um automatisierte Eingaben in Online-Formulare zu verhindern.

Datenexfiltration: Datenexfiltration ist der unbefugte Diebstahl von sensiblen Daten. Dabei werden vertrauliche Informationen aus einem System oder Netzwerk entwendet. Dies stellt eine erhebliche Bedrohung für die Datensicherheit dar.

Datenpanne: Datenpanne bezeichnet den unbefugten Zugriff auf sensible Daten. Sie umfasst auch den Verlust von Daten durch versehentliche Löschung oder Beschädigung.
Es handelt sich um einen schwerwiegenden Sicherheitsvorfall.

Datenschutz-Grundverordnung: Die Datenschutz-Grundverordnung ist eine EU-Verordnung, die die Verarbeitung von persönlichen Daten regelt. Sie vereinheitlicht die Regeln für Datenverarbeiter in der gesamten Union. Dies dient dem Schutz von Daten und dem freien Datenverkehr innerhalb des Binnenmarktes.

Deepfake: Deepfakes sind manipulierte Medien, die mithilfe von KI-Technologien erzeugt oder verändert werden. Sie können täuschend echt wirken und zur Verbreitung von Falschinformationen missbraucht werden. Sei vorsichtig bei Medien, die ungewöhnlich aussehen oder sich widersprechen.

Digitale Signatur: Die digitale Signatur basiert auf einem asymmetrischen Kryptosystem. Ein Sender nutzt einen geheimen Schlüssel, um eine digitale Signatur für eine Nachricht zu erstellen. Diese Signatur kann mit dem entsprechenden öffentlichen Schlüssel überprüft werden, um die Authentizität und Unveränderung der Nachricht zu bestätigen.

Digitales Zertifikat: Ein digitales Zertifikat dient der Identifizierung einer Person oder Organisation. Es verknüpft einen öffentlichen Schlüssel mit dieser Identität und wird von einer Zertifizierungsstelle ausgestellt. Die Gültigkeit des Zertifikats basiert auf einer digitalen Signatur, die die Authentizität sicherstellt.

DNS-Spoofing: DNS-Spoofing manipuliert die Domain-Name-Server-Zuordnung, um den Benutzer auf eine falsche Website zu locken. Das Ziel ist oft Phishing und das Eindringen in Privatsphäre durch Schadsoftware.

Domain Name System: Das Domain Name System, kurz DNS, übersetzt Domain-Namen in IP-Adressen. Es ermöglicht dem System, Webseiten und andere Dienste anhand ihres Namens zu finden. Der DNS ist ein Netzwerk von Servern, die diese Übersetzungen durchführen.

Drive-by-Download: Ein Drive-by-Download passiert, wenn du unbewusst Schadsoftware herunterlädst, indem du nur eine Website besuchst. Das Nutzen von Sicherheitslücken im Browser oder Betriebssystem macht das Risiko noch größer.

Emotet: Emotet ist eine Schadsoftwarefamilie für Windows, die sich über Makroviren verbreitet. Phishing-E-Mails führen zur Installation von Schadprogrammen, die dann Funktionen ausführen. Es ist eine bekannte Bedrohung, die sich durch ihre Anpassungsfähigkeit auszeichnet.

Heartbleed: Heartbleed war eine Schwachstelle in OpenSSL, die es ermöglichte, sensible Daten über verschlüsselte Verbindungen auszulesen. Die Lücke betraf OpenSSL-Versionen von 1.0.1 bis 1.0.1f und wurde durch ein Update am 7. April 2014 behoben. Viele Dienste waren betroffen, darunter Webseiten und Kommunikationsgeräte.

Honeypot: Honigtöpfe sind Einrichtungen, die Angreifer durch scheinbare Ziele anlocken sollen. Das Ziel ist es, die Aufmerksamkeit des Angreifers von den eigentlichen Systemen abzulenken. Der Begriff leitet sich von der Beobachtung ab, dass Bären durch Honigköpfe sowohl abgelenkt als auch in eine Falle gelockt werden.

HTTP-Cookie: HTTP-Cookies sind kleine Textdateien, die Webseiten in deinem Browser speichern. Diese werden vom Webserver über das HTTP-Protokoll an den Browser gesendet. Der Browser speichert diese Cookies und sendet sie zurück, wenn du die Webseite erneut besuchst.

Hypertext Transfer Protocol Secure: HTTPS ist ein Netzwerkprotokoll für die sichere Datenübertragung im World Wide Web. Es nutzt Verschlüsselung, um die Kommunikation abzusichern. Die Basis bildet TLS, das eine zusätzliche Sicherheitsschicht zwischen HTTP und TCP bietet.

Intrusion Detection System: Ein Intrusion Detection System analysiert Netzwerkverkehr auf verdächtige Aktivitäten. Es erkennt potenzielle Angriffe und protokolliert diese Ereignisse zur späteren Analyse. Ein IDS dient der Überwachung und Benachrichtigung über Sicherheitsvorfälle, ohne diese automatisch zu blockieren.

Kryptologische Hashfunktion: Sie nimmt Daten beliebiger Länge auf und verarbeitet sie zu einer festlängigen, unveränderlichen Kette von Zeichen, die als Hashwert bezeichnet wird. Dieser Hashwert ist sehr sensibel gegenüber Änderungen der Eingabedaten und fast eindeutig.

Multi-Faktor-Authentisierung: Multi-Faktor-Authentifizierung erhöht die Sicherheit, indem sie mehrere Zugangswege erfordert. Sie nutzt unterschiedliche Faktoren wie Passwörter und Codes, um unbefugten Zugriff zu verhindern. Empfehlungen dazu finden sich beispielsweise in den IT-Grundschutzkatalogen des BSI.

OAuth: OAuth ermöglicht die sichere Nutzung von Anwendungen durch Drittanbieter-Zugriff auf Ressourcen. Dabei werden Informationen ausgetauscht, ohne dass die Nutzerdaten des Anbieters direkt an die Anwendung weitergegeben werden. OAuth 2.0, das jüngere Protokoll, bietet verbesserte Sicherheit und Flexibilität.

Passwort-Manager: Ein Passwort-Manager speichert und verwaltet verschlüsselte Zugangsdaten für verschiedene Online-Dienste. Diese Programme sind für Desktop-Computer, Laptops und Smartphones verfügbar. Die Verwendung eines Passwort-Managers erhöht die Sicherheit deiner Konten erheblich.

Patch (Software): Ein Patch ist eine Korrekturauslieferung zur Behebung von Fehlern und Sicherheitslücken in Software. Er kann auch neue Funktionen einbeziehen, ohne dass die Nutzer es immer wissen. Größere Updates enthalten oft mehrere Patches zusammen.

PowerShell: PowerShell ist ein plattformübergreifendes Tool von Microsoft zur Systemautomatisierung und -verwaltung. Es kombiniert einen Kommandozeileninterpreter mit einer Skriptsprache und ermöglicht die Steuerung von Windows und anderen Systemen.

Public-Key-Infrastruktur: Die Public-Key-Infrastruktur ist ein System zur Verwaltung von digitalen Zertifikaten. Sie sichert Kommunikation durch die Verifikation von Identitäten und Schlüsseln. Zertifikate werden von vertrauenswürdigen Stellen ausgestellt und überprüft.

Ransomware-as-a-Service: Ransomware-as-a-Service, oder RaaS, ist ein Modell, bei dem IT-Dienstleister Ransomware-Software vermieten. Kunden nutzen diese Schadsoftware, ohne selbst entwickeln oder bereitstellen zu müssen.

Rechteausweitung: Rechteausweitung bedeutet, dass ein Benutzer oder eine Anwendung zusätzliche Berechtigungen erlangt, um auf Ressourcen zuzugreifen, die ihnen normalerweise nicht zugestanden sind. Dies kann durch Ausnutzung von Softwarefehlern oder Schwachstellen erreicht werden.

Sandbox: Sandbox bedeutet eine isolierte Umgebung, in der Aktionen getestet werden können ohne dass diese außerhalb des Sandboxes-Bereichs irgendeine Auswirkung haben.

Schadprogramm: Schadprogramme sind Computerprogramme, die unerwünschte oder schädliche Funktionen ausführen. Sie werden oft als Malware bezeichnet, was einen breiteren Schutz vor potenziell gefährlicher Software umfasst. Der Begriff Virus beschreibt dabei meist nur einen Teilaspekt des Schutzes vor Schadsoftware.

Secure Shell: Secure Shell, kurz SSH, ist ein Protokoll zur sicheren Kommunikation über unsichere Netzwerke. Es ermöglicht den Zugriff auf entfernte Systeme, beispielsweise zur Fernwartung eines Servers. Die aktuellere Version SSH-2 unterstützt zusätzlich die Dateiübertragung via SFTP.

Security Operations Center: Das Security Operations Center, kurz SOC, ist eine zentrale Stelle zur Absicherung von IT-Systemen vor Cyberbedrohungen. Es koordiniert alle sicherheitsrelevanten Dienstleistungen und umfasst sowohl technische als auch organisatorische Aspekte. Die Hauptaufgabe des SOC ist die kontinuierliche Überwachung und Reaktion auf Sicherheitsrisiken.

Sicherungskopie: Eine Datensicherung ist die Erstellung einer Kopie von Daten auf einem anderen Speichermedium. Dies dient der Wiederherstellung von Daten im Falle eines Datenverlustes. Es ist ein wesentlicher Bestandteil der Datensicherheit.

Single Sign-on: Single Sign-on vereinfacht den Zugriff auf verschiedene Systeme. Einmaliges Anmelden beim Identity Provider ermöglicht den Zugriff auf alle berechtigen Dienste. Dies reduziert die Belastung durch Passwortverwaltung.

Spam: Spam ist unerwünschte, massenhaft übermittelte Nachrichten, die ohne Zustimmung des Empfängers zugestellt werden. Spamming, oder Spammen, wird von Personen, den sogenannten Spammern, durchgeführt. Oftmals enthält Spam Werbung oder andere unerwünschte Informationen.

Spear-Phishing: Spear-Phishing ist ein spezialisierter Form von Phishing, bei dem der Angriff auf eine bestimmte Person oder Organisation zugeschnitten wird. Hierbei werden personalisierte Nachrichten und Links verwendet, um den Zielpersonal zu täuschen und sie dazu zu bringen, vertrauliche Informationen preiszugeben oder gefährliche Aktionen durchzuführen.

Steganographie: Steganographie ist die Technik, Informationen in einem unscheinbaren Trägermedium, wie einem Bild oder Audiofile, zu verstecken. Der Begriff leitet sich von „bedeckt schreiben“ ab und beschreibt die verborgene Übermittlung von Nachrichten. Ein solches, manipuliertes Medium wird als Steganogramm bezeichnet.

Stuxnet: Stuxnet ist ein Computerwurm, der 2010 entdeckt wurde und auf SCADA-Systeme mit Siemens Simatic S7 Steuerungen abzielt. Der Angriff richtete sich gegen Frequenzumrichter von Vacon und Fararo Paya, um deren Steuerung zu manipulieren. Dies stellt eine Bedrohung für industrielle Steuerungssysteme dar.

Tor (Netzwerk): Tor ist ein Netzwerk, das die Anonymität von Internetverkehr erhöht. Es leitet Datenpakete über mehrere Server um, um die Verfolgung zu erschweren. Tor wird für verschiedene Anwendungen genutzt, um die Privatsphäre der Nutzer zu schützen.

Transport Layer Security: Transport Layer Security verschlüsselt Daten im Internet, um sie vor unbefugtem Zugriff zu schützen. Es ersetzt das ältere SSL-Protokoll und wird bei HTTPS-Verschlüsselungen verwendet. TLS sichert beispielsweise Browser-Verbindungen und Server-Kommunikation.

Virtual Private Network: Ein Virtual Private Network schafft eine verschlüsselte Verbindung, die den Datenverkehr vor unbefugtem Zugriff schützt. Es ermöglicht den Zugriff auf Netzwerke wie ein Firmennetzwerk aus externen Standorten. Es gibt zwei Haupttypen: das konventionelle VPN und das virtuelle Privatnetzwerk im Sinne einer verschlüsselten Internetverbindung.

WannaCry: WannaCry war ein Ransomware-Programm, das 2017 weltweit verbreitet wurde. Es zielte auf Windows-Systeme ab, die nicht mit einem Microsoft-Patch aktualisiert wurden. Die Ransomware verschloß Daten und forderte Lösegelder in Kryptowährungen.

Windows-Registrierungsdatenbank: Die Windows-Registrierungsdatenbank ist die zentrale Konfigurationsdatenbank von Windows. Sie speichert Einstellungen für das Betriebssystem und Anwendungen. Sie ist seit Windows NT existent und hierarchisch aufgebaut.

Zertifizierungsstelle (Digitale Zertifikate): Eine Zertifizierungsstelle erteilt digitale Zertifikate innerhalb einer Public-Key-Infrastruktur. Das Zertifikat verknüpft einen öffentlichen Schlüssel mit einer Identität – beispielsweise einem Domainnamen oder einer E-Mail-Adresse. Die Zertifizierungsstelle bestätigt diese Zuordnung durch eine digitale Signatur.
