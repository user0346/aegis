AEGIS — Installation
=====================

⚠ ZUERST LESEN — falls Windows die Installation blockiert
---------------------------------------------------------
Windows 11 (Smart App Control / SmartScreen) markiert ALLES aus einem
heruntergeladenen ZIP als "aus dem Internet" (Mark-of-the-Web) und blockiert
dann unsignierte Dateien — auch install.cmd, oft sogar OHNE einen
"Trotzdem ausfuehren"-Knopf. AEGIS ist echt und quelloffen, nur noch nicht
von Microsoft signiert (die Signierung ist geplant).

So loest du das EINMAL und sauber — die Internet-Markierung VOR dem Entpacken
entfernen:
   1. Rechtsklick auf die heruntergeladene Datei  AEGIS.zip
   2. -> Eigenschaften
   3. unten bei "Sicherheit": Haekchen "Zulassen" (engl. "Unblock") setzen
   4. -> OK
   5. ERST JETZT entpacken. Die entpackten Dateien sind dann nicht mehr
      blockiert, und install.cmd startet normal.

Schon entpackt? Dann genuegt EINE Zeile in PowerShell (Pfad ggf. anpassen):
   Get-ChildItem -Recurse "$env:USERPROFILE\Downloads\AEGIS" | Unblock-File
Danach install.cmd doppelklicken.

(Voellig ohne Warnung geht es erst mit Microsoft-Code-Signatur — das ist ein
 kostenpflichtiger Schritt und kommt spaeter; die Unblock-Methode oben ist
 sicher und reicht in der Zwischenzeit.)


EMPFOHLEN: install.cmd (nach dem Unblock oben — Windows 10/11)
-------------------------------------------------------------
Voraussetzung: Python 3.11 oder neuer von https://www.python.org/downloads/
  -> beim Setup unbedingt "Add python.exe to PATH" anhaken.

1.  Diesen Ordner ist egal wo entpackt — einfach in diesem Ordner die Datei
       install.cmd
    doppelklicken.

2.  install.cmd erledigt automatisch ALLES:
      - installiert die benoetigten Pakete,
      - legt AEGIS am richtigen Ort ab (%LOCALAPPDATA%\Programs\AEGIS),
      - richtet Autostart, Verknuepfung und die Integritaets-Basis ein,
      - startet AEGIS.

    Den heruntergeladenen Ordner darfst du danach loeschen — AEGIS laeuft aus
    seinem eigenen Installationsordner und startet ab jetzt mit Windows.

Das war's. AEGIS schuetzt im Hintergrund; das Fenster kannst du jederzeit
schliessen. Ueber das Tray-Icon kannst du es wieder oeffnen oder den Schutz
ganz stoppen.


Hinweis zur AEGIS.exe (.exe-Version)
------------------------------------
Es gibt zusaetzlich ein Bundle "AEGIS-windows-x64.zip" mit AEGIS.exe. Auch diese
.exe ist noch nicht Microsoft-signiert und wird von Smart App Control / SmartScreen
blockiert — genau wie install.cmd. Die Loesung ist dieselbe wie ganz oben: die ZIP
VOR dem Entpacken per Rechtsklick -> Eigenschaften -> "Zulassen" entsperren (oder
nachtraeglich mit Unblock-File). Danach laeuft sie. Die signierte .exe kommt,
sobald die Code-Signierung steht.


Bedienung — alles ist ein Knopf in der App
------------------------------------------
Einstellungen -> System:
  - Ersteinrichtung        (Autostart + Verknuepfung + Baseline)
  - Autostart EIN / AUS
  - Integritaet neu pinnen (nach einem bewussten Update)
  - Neustart               (sauberer Neustart von Schutz + Oberflaeche)


Optionale Funktionen (standardmaessig aus)
------------------------------------------
- Lokale KI (Ollama): in der App -> Einstellungen aktivieren. Laeuft lokal.
- Sprachsteuerung:    in der App -> Assistent aktivieren.
  (Sprach-EINGABE braucht zusaetzlich: pip install -r requirements_v2_voice.txt)
Kein Konto, kein API-Key noetig.


Sicherheits-PIN
---------------
Setze in den Einstellungen einen Owner-PIN, um autonome Aktionen zu schuetzen und
den Stopp des Schutzes mit PIN abzusichern.


Updates
-------
Neue Versionen zeigt dir die App selbst an und installiert sie nach deiner
Bestaetigung (signaturgeprueft via cosign / Sigstore).


Deinstallation
--------------
1.  Einstellungen -> System -> Autostart AUS, dann Tray -> "Schutz stoppen".
2.  Loesche den Ordner %LOCALAPPDATA%\Programs\AEGIS und die Verknuepfung.
